# SalonBook Client

Next.js App Router frontend for SalonBook.

## Local development

1. Use Node.js 20.9 or later.
2. Run `npm install` in this repository.
3. Copy `.env.example` to `.env.local` and set `NEXT_PUBLIC_API_URL` to `http://localhost:4000`.
4. Run `npm run dev` and open `http://localhost:3000`.

## Environment variables

See `.env.example`. Never commit `.env.local` or other files containing credentials.
